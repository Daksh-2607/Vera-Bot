================================================================================
ENDPOINTS IMPLEMENTED
================================================================================

POST /v1/context
  Request:  scope, context_id, version, payload, delivered_at
  Response: 200 OK or 409 Stale Version
  Features: Idempotent versioning, atomic replacement

POST /v1/tick
  Request:  now, available_triggers[]
  Response: {"actions": [TickAction]}
  Features: Trigger ranking, composition, conversation creation

POST /v1/reply
  Request:  conversation_id, merchant_id, message, turn_number
  Response: ReplySendAction | ReplyWaitAction | ReplyEndAction
  Features: Intent recognition, auto-reply detection, state routing

GET /v1/healthz
  Response: {status, uptime_seconds, contexts_loaded}
  Features: Liveness probe, context counting

GET /v1/metadata
  Response: {team_name, team_members, model, approach, version}
  Features: Bot identity and submission info
